# Pharmacy Inventory and Sales System

## Overview

Pharmacy Inventory and Sales System is a Python console application that manages medicine inventory, tracks stock quantities, calculates inventory statistics, and generates a pharmacy summary report.

The project demonstrates how lists and functions can be combined to organize and process inventory data.

## Features

- Add medicine names
- Record medicine prices
- Record stock quantities
- Validate user input
- Display stock status
- Track out-of-stock medicines
- Find the most expensive medicine
- Find the cheapest medicine
- Calculate total inventory value
- Calculate total stock quantity
- Generate a pharmacy summary report

## Python Concepts Used

- Functions
- Parameters
- Return values
- Lists
- For loops
- While loops
- Conditional statements
- Input validation
- Searching
- Maximum and minimum value algorithms
- Accumulators

## Future Improvements
